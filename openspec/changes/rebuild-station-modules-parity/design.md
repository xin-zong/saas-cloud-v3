# Design

## Context
本次基准为用户提供的两张同站截图及既有本地实屏/公开源码清单。当前工作区基线507f893，分支develop-toyingzhen。QUDEOX参考保持只读；不进入有挂载自动写入的能量管理等页面。

## Goals / Non-Goals
目标：参考页面结构/功能一致、所有展示值落新库、完整可验证的本地模拟业务、逐模块证据闭环。
非目标：改造图引擎、真实设备远控、对参考平台写入、绕过权限、宣称实现未知算法、将mock称实时测量。

## Decisions
1. 按模块串行重做；先冻结证据/控件清单，再模型/API/页面/交互/实屏验收。截图可证实内容是最低验收要求，不能反向从当前代码生成“已核验”清单。
2. 布局优先于组件皮肤。Tabler/shadcn可复用基础控件，但不能增加卡片边框、胶囊页签、留白或改变参考的三列/双列、表格列、工具栏。
3. 分场站系统组合决定可见菜单与场景；新疆截图只证明其菜单，不足以说明所有储能站都如此。将已确认配置存入库，未确认条件补证据。
4. mock不是前端DEMO分支：幂等seed写入独立新库的可关联数据集；接口与本地CRUD沿用同一业务链路。每批有dataset/version/sourceTime，真实记录不覆盖；归档/清理限定数据集。前端无imported快照分区，API保留来源说明。
5. 非时间实时采样的mock值不能刷新为当前时间；告警/策略可用本地模拟事件推进状态，操作与结果均落库并明确未发真实指令。
6. main固定基线8cfcc30b466022632c60f29f353a84575757138c，EnergyFlowDiagram.tsx和EnergyFlow3D.tsx禁止修改。只在调用层映射数据与布局；原接线图对应关系需核对main调用，不能只改标题偷换业务。
7. 原权限检查、乐观锁、事务、审计、跨站过滤保持；不复制参考用户权限和身份。

## Implementation boundaries
页面拆成独立组件与typed view model；Dashboard不再同时承载分析业务。共用shell只负责站点身份/菜单/刷新，不能把各类型设备详情压成一份通用字段卡。mock seed不得掺进迁移中大批覆写已有资料，迁移只建结构/约束，seed单独可重放。

## Risks / Trade-offs
- 既有证据有不同日期/语言/场站，禁止混屏拼成不存在的页面。
- 截图值与当前库值可不同：验收固定数据集，不用当前采样倒推截图值；旧真实数据保持不变。
- 部分参考页面挂载自动写入或外域凭据交换，仅能用已保存证据/静态分析；不足处标记待核验。
- 模拟远控闭环只验证本地指令/状态/日志，不证明设备协议接入。
- 原图内部可能有默认演示数；接回时必须在外部传入库数据并审查默认回退。

## Migration / Rollback
结构仅新增下一版本迁移；前置断言DB=ems_cloud_saas_toyingzhen与owner=ems_toyingzhen_owner。seed以datasetId隔离、事务导入、有唯一键、重复运行幂等。回滚仅清理本批dataset/恢复功能开关，不回退已被用户更新的数据，不删除历史业务表。每模块独立commit；不推送/部署线上。

## Open Questions tracked as tasks
哪些站型显示系统布局、各类型完整详情/写入返回、能量管理真实回执含义、智能分析公式、License规则仍需证据。它们是待核验条目，不允许靠猜测补全。用户已经给出图库保留和mock许可，无需重复询问这两点。
