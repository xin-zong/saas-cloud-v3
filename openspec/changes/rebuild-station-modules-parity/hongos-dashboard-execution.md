## 流向契约

电网正值为购电入站、负值为并网出站；储能正值为充电、负值为放电，仅在数据集明确声明此符号约定后适用。光伏正值为发电出端，用电正值为负荷消耗。未取得支路测点时只显示节点到公共母线的方向，不猜光伏到电池的分配量；不通过平衡公式伪造独立实测。零值不动画，缺失不当作零。
