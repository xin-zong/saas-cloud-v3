## 已落地的入口与功能

- **总览 → 经营看板；站点 → 站点概览**：场景、通信状态与站点过滤，真实容量和设备统计，PV/储能实测功率历史、采样粒度、排名、CSV导出。私人看板布局保存到服务器，带版本冲突、越界/重叠校验。
- **站点 → 设备详情**：逆变器、储能柜、PCS、电池簇、电池堆、空调、电表、采集器、EMS九类目录；分类档案、实时参数、参数选择/历史曲线、连接关系、设备告警、版本与操作日志。本地理论SOH/循环次数和参数选择保存到数据库，带权限与版本校验。
- **电站管理 → 运维总览 → 告警事件；站点 → 告警信息**：实时/历史/全部事件，高级筛选、分页、详情、个人已读/批量已读、确认、备注、人工关闭、终态软删除。个人已读、业务确认、自动恢复、人工关闭分别记录；处置可追溯。
- **告警 → 规则管理**：规则增删改查、单/双指标条件及边界校验、时段、恢复时长、独立启停、通知偏好与收件人校验，保留规则修订历史。
