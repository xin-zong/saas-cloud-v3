## 实现

- 自动布局修正手动移动后的柜内偏移，适配多个柜体、独立设备及自定义尺寸；连线采用水平/垂直路径并避开卡片。大尺寸 ATS 来源及窄间距的路由问题有回归覆盖。单次撤销恢复布局，XML 身份及业务配置保持一致。
- 完整保留一期助手界面，通过独立同源入口加载 Vue 组件，避免一期样式影响当前 React 页面。保留流式消息、简洁/深度思考、停止生成、多站点与时间范围、附件、图表、证据、风险提示、历史会话、MD/PDF/DOCX、调整宽度和全屏。
- 接入当前账号、授权站点、语言、主题及 IANA 时区。关闭后保留未发送内容；退出账号时销毁实例。权限与站点范围变化会中止回答并清除失效缓存。
- `/api/agent/v1/*` 使用当前登录鉴权，服务端覆盖身份、只读权限和站点范围，强制 `dry_run`。会话和附件归属使用两张规范化关系表，带主键、外键及枚举检查；不保存 CSV 范围或无用途字段。
- 一期生产配置实际指向 `http://47.99.70.238:18080`。已验证真实健康接口与 32 项工具目录。密钥只从现有服务端私有配置读取，不进入 Git 或前端资源。
- 当前 SaaS 站点 ID 经数据库映射为其真实 `station.code`，不按名称猜测一期站点。若一期数据服务未登记当前站点代码，保留真实的目录不匹配提示。旧页面专属自动填表/写入动作没有冒充成功；当前页面无适配器时明确返回不可用。
