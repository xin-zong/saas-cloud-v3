## XML 映射

- 根节点固定为 `SiteTopology schemaVersion="draft-2" status="Draft"`，保留稳定 `configSetId`、`siteId`、`revision`、`siteCode` 和目标 `emsRef`。
- 电池系统映射 `EMU`；嵌套液冷映射独立 `TMS`；嵌套电网/光伏计量映射独立 `GridMeter`/`PVMeter`。显示名称、画布位置与稳定 ID 分离，改名、拖动、移柜不能改写引用。
- 光伏 DC/DC 使用受控类型 `PVDC`。标准柜使用 `Groups/Group type="Cabinet"`，柜号与显示名分离；成员只在 `Member nodeRef` 中表达，不通过连线或布局推断。
- EMS 身份、接口、DHCP/静态网络、RS485 参数与外部 Peers 分别映射 `EmsIdentity`、`Interfaces`、`Network`、`SerialSettings`、`Peers/Ems`。
- 直连、转发、不通信分别映射 `Direct`、`Forwarded`、`None`；转发只生成 `viaRef`，不伪造设备地址。DI 只生成 `DigitalInput`，有效电平与信号含义可编辑，控制必须明确关闭。
- 电气线路保留稳定线路 ID 和两个有序 `Endpoint`，持久化 `ac`、`dc`、`bus` 或 ATS 的 `sourceA/sourceB/common` 端口。计量引用线路，并明确 `Endpoint1To2` 或 `Endpoint2To1`，不通过连线绘制方向推测功率正方向。
- 未生成实际运行参数文件时，不输出 `RelatedFiles`。CAN 和其他预留接口不模拟已经具备可执行协议。

参考示例包含 9 个 XML 节点、3 个 EMS 接口、5 条电气线路、1 个标准柜。界面将温控和进线电表嵌入对应设备的属性面板，导出时仍是独立 XML 节点。示例厂家与型号显示其参考来源，不冒充在线设备适配认证。
