## 尚未接通的边界

- 云端尚无 SMTP 配置。企业申请、员工邀请和一次性激活邮件不能完成外部投递；未配置时明确不可用。本机 SMTP sink 的结果不等于云端发信成功。
- EMS 草稿下发、现场部署、自检和正式版本反馈仍明确显示未接通；跨企业合作派单仍待业务确认，企业间保持隔离。
