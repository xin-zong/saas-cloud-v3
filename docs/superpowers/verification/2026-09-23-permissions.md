# 角色与成员授权实施验收记录

## 基线与边界

- 当前代码基线已上传至 `https://github.com/xin-zong/saas-cloud-v3.git`，`main` 提交为 `541c73c53bf4ff4ec56e925cf0f70055b561839d`；已核对本地与远程提交一致。
- 权限改动在独立分支 `feat/prototype-permissions` 实施，原始主分支保留。
- 仅使用新业务库 `ems_cloud_v2_proto`。ClickHouse 遥测结构没有因本次权限改动而调整。
- 截至 T04 验收，运行库仍为迁移版本 1–5；V6–V8 只做回滚演练。正式切换需在完整前后端完成后重新备份并停止旧 API。
- 初始角色配置管理员账号尚待用户指定；迁移不会自动扩大已有成员权限。

## 待补验收

- T04 审查指出一项测试证据改进：到期用例尚未精确区分“等于截止时刻”和“已超过截止时刻”。实际 SQL 使用排他的截止条件；T11 补同一数据库语句时刻的边界测试。
- T05 角色管理、后续逐条授权、前端配置页面及成员组织流程仍须分别完成实现和独立审查。
- 最终验收须覆盖三种身份的二级页面、两个视口、真实 API 操作、权限撤销后的已登录会话，以及原型布局和空态。
