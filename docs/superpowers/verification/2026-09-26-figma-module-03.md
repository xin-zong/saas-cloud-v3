## 接口、表单与权限

- 未修改 `/market-drafts`、`/market-drafts/{id}/cancel`、`/stations/{id}/market-services`、`/stations/{id}/qualifications`、内部计划／提交审批、结算／复核接口契约。
- 本地邀约／参与与拒绝意向、调度与交接建议按 `API/demo : user.id : 业务对象` 隔离；存储失败显示错误，不能进入已保存状态。生产演示角色保持原限制。
- 所有新的编辑表单使用现有 `useEditorLeaveGuard`；确认前校验、浏览器离开、主导航／子导航／退出登录保护；撤销管理权限关闭编辑／确认并取消待离开请求。
- 未把额定功率当作市场可用功率。调度建议的额定功率仅作为本地输入上界，不能替代联锁检测或批准执行。
- 共享顶栏：除总览外的业务模块复用 StationGlobalHeader；保留 56 px 顶栏、176/64 px 侧栏网格。退出登录调用 `requestActiveEditorLeave`。02 资产与站点的视觉作用域保持不变。
