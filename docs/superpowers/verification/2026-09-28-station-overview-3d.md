# 站点概览设备图 / 3D 切换

## 设计依据

- 本次读取 Figma 文件 `Y0KMYFvalDXgSPnVZ5zG39` 最新设计上下文及截图。
- 选用 `2044:8026`：P021 · 站点概览 · 克制风格探索；系统入口：资产与站点 → 打开站点 → 站点概览。
- 保留该设计的设备图、340px 能流卡片、右侧设备详情及下方趋势布局。按用户恢复功能的要求，在能流卡片左上角增设设备图 / 3D 分段按钮。

## 实现

- 复用原有 EnergyFlow3D 几何模型，按需加载；支持旋转、缩放、模型及标签选择，联动右侧设备分类。
- 3D 为分类布局示意，并非数据库中真实空间位置。连接不播放未经遥测确认的流向动画。
- 3D 与设备图使用同一份格式化指标；缺失值显示 --，删除原有容量推算功率的错误换算。
- 保留只读展示；切换不写数据库、不开放设备布局编辑，不增加权限或接口。
- WebGL2 不可用及场景加载失败时显示可恢复提示；设备图按钮始终可用。
