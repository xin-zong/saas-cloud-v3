# 总览与全屏二次优化

重新读取 Figma 地图 `1172:26660` 和全屏 `1286:2252` 的高保真上下文及截图（文件 Y0KMYFvalDXgSPnVZ5zG39）。复用现有地图、卡片、图表，不替换设计资产。

- 普通与全屏共用自适应网格；全屏实时指标移入左栏、事件日志移入右栏，取消绝对定位造成的覆盖。

- 全屏实时指标改用中文；数值保持真实空态，不生成虚构频率或碳减排数值。
