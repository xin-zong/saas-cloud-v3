## 本次修改

- 正式建站流程移除“载入工商业参考示例”、提示及确认分支；不默认填入示例站点。四种正式起始模板保留。参考包仅由测试夹具恢复，用于 XML 契约与功能验收；生产 JavaScript 不含参考示例数据。
- 旧个人草稿保留，不自动删除。显式更换模板时修复原可选 EMS 引用，防止保留指向被替换设备的悬空引用；其余元数据、基本信息和运行参数保留。
- 精细三栏：184px 节点库、弹性画布、296px 属性栏；宽屏节点库208px。工具栏28px按钮和44px比例按钮，输入34px，节点与属性层级统一，完整标签和搜索空态。

- 新模板柜体居中，柜内标题/PCS/母线/电池留白调整；已有自定义柜高兼容，显式节点位置不重写。适应画布按实际可见节点范围居中，窗口变化使用最新布局。
- 比例按钮真正重置100%；空白点击取消选择，平移保留选择；Ctrl+Y重做；全屏连线中第一次Esc取消操作，第二次退出全屏。保留撤销、缩放、端口连线、拖拽、尺寸调整及XML导出。
- 深色模式补齐母线、嵌套表单、图标和摘要对比，静态语言词条补齐。
