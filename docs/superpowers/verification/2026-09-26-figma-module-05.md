## 接口、权限与草稿

- 工单创建继续 `POST /work-orders`；负责人 `PUT /work-orders/{id}/assignee`；记录 `GET .../events`、`POST .../notes`；状态流转保留 `expectedStatus`，仅 pending→processing/cancelled、processing→completed/cancelled。
- 巡检创建及 complete/cancel 使用原接口。三项检查合并为真实 `note`，不会把附件或新结构化字段伪装成服务器已保存。
- 审批仅复用本任务约定的运行计划 decision approved/rejected；补充要求是本地草稿。缺版本/风险/预检信息不伪造。
- 新建、审批意见、处理记录、巡检、转派和任务协作表单均接入共享离开保护，含关闭、Escape、外层导航、刷新/关闭浏览器。放弃恢复实际字段。部分权限撤销取消尚未完成的跳转并清除不可访问对象。
- 新草稿键为 `enerlution-workflow-v1:<api|demo>:<account>:<station>:<kind>:<object>`。既有demo工单/意见/覆盖状态也追加模式和账号作用域。存储失败显示错误。
